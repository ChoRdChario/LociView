# 08. iOS実機検証ガイド（P0-2）

> Status: `V1 QA RUNBOOK`. This is not a GS/mobile-memory acceptance specification for v2.

**公開URL: https://chordchario.github.io/LociView/**

設計時から「最重要検証」としてきた項目です。iOSはブラウザ制約が最も厳しく、ここが通れば
他のプラットフォーム（Android・PC）は問題なく動きます。

所要時間の目安: 15〜20分。**結果を「OK / NG（何が起きたか）」でメモしていただければ十分です。**

---

## 事前準備

- iPhone または iPad（iOS 16.4以降が望ましい。設定→一般→情報 で確認できます）
- Safari を使用（Chrome for iOSでも動きますが、ホーム画面追加はSafariが確実です）

---

## テスト1: 起動と表示（3分）

1. Safariで **https://chordchario.github.io/LociView/** を開く
2. 「プロジェクト（ZIP）をここにドロップ」の画面が出るか
3. 「新規プロジェクト」→ 名前を入れて「OK」
4. ビューア画面が開き、下からパネル（ボトムシート）が出るか
5. パネル下部のタブが **Caption / Material / Model / Views / データ** の5つあるか

**確認したいこと**: レイアウトが崩れていないか。文字が小さすぎ・はみ出しがないか。

---

## テスト2: ホーム画面に追加（オフラインの要）（3分）

1. Safariの下部（または上部）の **共有ボタン**（□に↑のアイコン）をタップ
2. 「**ホーム画面に追加**」を選ぶ
3. ホーム画面に **LociView のアイコン**（黄色いピンとキャプション枠の絵）が出るか
4. **一度Safariを閉じ**、ホーム画面のアイコンから起動する
5. Safariのアドレスバーが無い、アプリのような画面で開くか

**確認したいこと**: アイコンが正しく表示されるか。アプリとして起動するか。

---

## テスト3: オフライン起動（最重要）（3分）

1. **機内モードをON**にする（コントロールセンターの飛行機マーク）
2. ホーム画面の LociView アイコンから起動する
3. **起動するか**（真っ白な画面やエラーにならないか）
4. 「新規プロジェクト」を作り、ビューア画面まで進めるか

**確認したいこと**: ネットが無くても起動して使えるか。
→ **これが動けば、このアプリの存在理由（現場で電波が無くても記録できる）が成立します。**

機内モードのまま次のテストへ進んでください。

---

## テスト4: 3Dモデルの表示とピン打ち（5分）

※ 機内モードのままで構いません。

まずテスト用の3Dファイルが必要です。**次のいずれか**で用意してください。

- 手持ちのGLB/OBJ/STL/PLYファイルがあれば、iPhoneの「ファイル」アプリに入れておく
- 無ければ、機内モードを一度解除して
  **https://chordchario.github.io/LociView/samples/cube.stl** を Safariで開き、
  共有ボタン →「ファイルに保存」で保存（その後また機内モードでOK）

手順:

1. アプリで「データ」タブ →「モデルファイルを追加」
2. ファイルアプリから 3Dファイルを選ぶ
3. **モデルが表示されるか**
4. 指1本でドラッグ → 回転するか。2本指でピンチ → 拡大縮小するか
5. モデルの上を **長押し**（0.5秒くらい）→ **ピンが立つか**
6. ピンが立つと下のパネルが開き、タイトル入力欄が出るか
7. タイトルを入力 → キャプション一覧に反映されるか
8. 一度パネルを下げ、**ピンをタップ** → 選択され、
   **ピンから線が伸びたキャプションのウィンドウ**が出るか

**確認したいこと**: 長押しでピンが立つか（誤操作なく）。回転・拡大がスムーズか。

---

## テスト5: 保存と受け渡し（5分）

1. 「データ」タブ →「フルZIP」をタップ
2. **書き出しができるか**（ファイル保存または共有シートが出るか）
3. 保存できたら、**アプリを完全に終了**（アプリスイッチャーで上にスワイプ）
4. もう一度ホーム画面から起動
5. ホーム画面（左上の ☰ ボタン）に **さっきのプロジェクトが残っているか**
6. 「開く」→ **モデルとピンが復元されるか**

**確認したいこと**: 作業内容が消えずに残るか。書き出したファイルをメール/LINE/Driveへ送れるか。

## 補足: 既知の制約（NGではありません）

- **iOSではファイル関連付けができません**。`.lociview` ファイルをタップしても
  LociViewは起動しません。アプリ内の「データ」タブから開いてください（設計どおりです）
- 共有シートからLociViewへ直接送る機能もiOSでは非対応です（Androidのみ）
- 巨大なモデル（数百MB）は端末のメモリ次第で読み込めない場合があります
