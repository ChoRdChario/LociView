# 07. ロードマップと未決事項

## Phase 0 — 技術PoC（設計の裏取り。作り込まない）

リスクの高い仮説だけを最小コードで検証する。

- [ ] P0-1: op-log reduce の決定性 — OpLogEngineをスタンドアロン実装し、シャッフル/分割/重複投入のプロパティテストが通ること
- [ ] P0-2: iOS Safari実機で OPFS書き込み + ZIP取込 + Web Share書き出しの一周が動くこと（**最重要**。ここが崩れるとモバイル戦略の見直しが必要）
- [ ] P0-3: zip.js ストリーミングで500MB級ZIPをOPFSへ展開できること（デスクトップ/iOS）
- [ ] P0-4: Drive フォルダZIPダウンロードの実物構造確認（xlsx変換・文字コード・ネスト構造）
- [ ] P0-5: 中位Androidで100万点PLYの表示フレームレート実測（ユーザー実データのPLYを借用して行うのが望ましい）

## Phase 1 — MVP（UC1・UC2・UC4が完結する）

- プロジェクト開閉・ワークスペース・自動保存・ZIPエクスポート
- GLB / OBJ / STL / PLY（点群は点サイズ+頂点色の基本表示）
- Caption/Material/Views タブのLociMyu機能同等 + **表示セット切替**（FR-13）
- ピン・キャプション編集（op-log裏打ち）、ユーザープロファイル
- **Undo/Redo**（FR-14）、**キャプション検索・絞り込み**（FR-15）
- 添付は `attachments` + asset `kind` で汎用化（UIは画像のみ。映像/音声はデータ仕様のみ先行）
- マージ（ZIP投入→レポート表示）
- CSV/xlsxインポート・エクスポート（UTF-8 BOM・完全精度座標・modelName一括付替え）、エクスポートZIPへの閲覧用captions.csv同梱、Drive ZIPインポートウィザード（LociMyu移行含む: シート→表示セット変換、画像手動リンクUI + fileId対応表CSV補助）
- PWAオフライン起動、デスクトップ+スマホのレスポンシブUI
- セキュリティガード一式（docs/02 §8）

**MVP完了基準 = docs/01 の成功基準1・2・3をすべて実演できること。**

## Phase 2 — フォーマット拡張と運用強化

- **その場カメラ撮影→添付**（FR-26。Phase 2の最優先）
- **変更履歴ビュー・時点表示**（FR-27）、**現在ビューのPNG書き出し**（FR-28前半）、**映像添付の再生UI**（FR-31）
- FBX、PCD、点群UI強化（色モード拡張・自動サブサンプル）
- 差分ZIP書き出し（opsのみ）、Android share_target、パース済みキャッシュ
- 迷子ピン再配置UI、マテリアル再割り当てUI、競合の手動解決UI、CSV手編集の自動検出（FR-33）
- モデル差し替え（同一assetId実体更新）とピン追従

## Phase 3 — 大規模データと周辺連携

- **自己完結ビューアHTML書き出し**（FR-29）、**整形レポートHTML/PDF**（FR-28後半）
- **計測ツール + スケール校正**（FR-30）
- LAS/LAZ（laz-perf WASM。需要確認後）、点群LOD検討
- 複数モデル同時ロード（FR-22）、**表示セットの重ね合わせ表示**（FR-32）
- クラウド同期プロバイダ（Drive等）のオプション再接続 — コアと分離したモジュールとして。LociMyu監査のOAuth知見をここで再利用
- コンパクション（ログ肥大対策）

## 確定済み事項（2026-07-16 ユーザーヒアリング）

| # | 決定 |
|---|---|
| U-03 | シート切替は**表示セット**として第一級で継承する。実運用は「マテリアル透明度・Unlit等の見え方」×「その見え方に合わせたキャプション位置」×「ビュー」を束ねた見え方セット（半透明セット=内部ピン、通常セット=表面ピン等）であり、単なる分類ではない。廃止案は撤回。データ仕様は docs/02 §5 `set`、UIは docs/05 §2 |
| U-05 | 移行対象は1プロジェクト・約200キャプション・View設定あり。LociMyu本体の改修はせず、移行ウィザードの手動リンクUI + 任意のfileId対応表CSV（ユーザー自身のApps Scriptで生成。スニペットを移行ガイドに同梱）で対応する |
| U-06 | 点群はPLY想定 → PLYをMVPへ引き上げ（点サイズ+頂点色の基本表示）。PCDはPhase 2、LAS/LAZは需要確認後へ格下げ |
